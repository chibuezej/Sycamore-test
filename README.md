
## Get started

1. Install dependencies

   ```bash
   npm install
   ```

2. Start the app

   ```bash
   npx expo start
   ```


## Requirement Covered

Requirements Covered

Merchant name, amount, currency, date, category icon, and status displayed
Currency formatting via Intl.NumberFormat (NGN, USD, etc.)
Distinct status colors and icons for pending/completed/failed
onPress support with subtle pressed state (opacity + scale)
Fully typed with TypeScript interfaces
Long merchant names truncated using numberOfLines={1} and ellipsizeMode="tail"
Reusable and scalable for production fintech applications
